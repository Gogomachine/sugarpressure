# SugarPressure Bot

Telegram-бот для отслеживания артериального давления и уровня глюкозы в крови.

## Возможности

- **Голосовые сообщения** — отправьте аудио: «Давление 120 на 80», «Глюкоза 5.4»
- **Текстовые сообщения** — напишите: `Давление 120/80`, `Сахар 6,2`
- **История** — просмотр последних записей (`/history`)
- **Графики** — динамика давления и глюкозы с зонами нормы (`/chart`)
- **Выгрузка для врача** — CSV и PDF отчёты (`/export`)

## Установка

```bash
# Клонируйте репозиторий
git clone <repo-url>
cd sugarpressure

# Создайте виртуальное окружение
python3 -m venv venv
source venv/bin/activate

# Установите зависимости
pip install -r requirements.txt

# Скопируйте и заполните конфиг
cp .env.example .env
# Отредактируйте .env — укажите TELEGRAM_BOT_TOKEN
```

## Получение токена бота

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте `/newbot` и следуйте инструкциям
3. Скопируйте полученный токен в `.env`

## Запуск

```bash
python main.py
```

## Команды бота

| Команда | Описание |
|---------|----------|
| `/start` | Приветствие и инструкция |
| `/help` | Справка по использованию |
| `/history [дней]` | Показать историю записей (по умолчанию 30 дней) |
| `/chart [дней]` | Графики давления и глюкозы (по умолчанию 30 дней) |
| `/export [дней]` | Выгрузка CSV + PDF для врача (по умолчанию 90 дней) |

## Примеры ввода

**Текстом:**
- `Давление 120/80`
- `Давление 130 на 85 пульс 72`
- `Глюкоза 5.4`
- `Сахар 6,2`

**Голосом:**
- «Давление сто двадцать на восемьдесят»
- «Глюкоза пять и четыре»

## Структура проекта

```
sugarpressure/
├── main.py              # Точка входа
├── requirements.txt     # Зависимости
├── .env.example         # Шаблон конфига
├── bot/
│   ├── handlers.py      # Обработчики команд и сообщений
│   ├── parser.py        # Парсинг текста → давление/глюкоза
│   ├── voice.py         # Распознавание голоса (faster-whisper)
│   ├── database.py      # SQLite база, модели SQLAlchemy
│   ├── charts.py        # Генерация графиков (matplotlib)
│   ├── export.py        # Выгрузка CSV + PDF для врача
│   └── fonts/           # Шрифт DejaVu для кириллицы в PDF
```

## Системные требования

- Python 3.11+
- ffmpeg (для обработки голосовых сообщений)

```bash
# Ubuntu/Debian
sudo apt install ffmpeg

# macOS
brew install ffmpeg

# Windows
winget install ffmpeg
```

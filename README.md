# SugarPressure Bot

Telegram-бот для трекинга артериального давления и уровня глюкозы (сахара) в крови.

## Возможности

- **Голосовой ввод** — отправьте голосовое сообщение: "Давление 120 на 80" или "Глюкоза 5.4"
- **Текстовый ввод** — напишите то же самое текстом
- **Графики** — визуализация динамики давления и глюкозы за 30 дней
- **Выгрузка для врача** — экспорт данных в PDF и CSV

## Установка

### 1. Системные зависимости

```bash
# Ubuntu/Debian
sudo apt update && sudo apt install -y ffmpeg python3-pip

# macOS
brew install ffmpeg
```

### 2. Python-зависимости

```bash
pip install -r requirements.txt
```

### 3. Получите токен бота

1. Откройте Telegram, найдите [@BotFather](https://t.me/BotFather)
2. Отправьте `/newbot` и следуйте инструкциям
3. Скопируйте полученный токен

### 4. Настройте переменные окружения

```bash
cp .env.example .env
# Отредактируйте .env и вставьте токен бота
```

### 5. Запуск

```bash
export TELEGRAM_BOT_TOKEN="ваш-токен"
python bot.py
```

## Использование

| Действие | Команда / сообщение |
|---|---|
| Записать давление | "Давление 120 на 80" или "120-80" |
| Записать глюкозу | "Глюкоза 5.4" или "Сахар 5,4" |
| График давления | /pressure или кнопка |
| График глюкозы | /glucose или кнопка |
| История записей | /history или кнопка |
| Выгрузка для врача | /export или кнопка |

## Структура проекта

```
bot.py        — главный файл бота, обработчики команд
database.py   — работа с SQLite базой данных
parser.py     — распознавание значений из текста
speech.py     — распознавание речи (Whisper)
charts.py     — генерация графиков (matplotlib)
export.py     — экспорт в PDF и CSV
```
